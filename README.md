# GROUNDS v35.3 — Site alignment and street movement

Upload the contents of this ZIP to the root of the existing GitHub Pages repository. A browser refresh and the in-game update button load the new service worker version.

- Nine site-specific plot registrations align the placement boundary and stadium grid with each illustrated parcel.
- Traffic routes traced from each illustrated day map replace the single short road segment. Vehicles use roads, walkers use adjacent pavement offsets, and actors begin across different streets. Larger site tiers have more ambient actors.
- Three starting stadium layouts per starting division, with capacities calculated from the actual stand sections in the picker. Championship starting bowls seat 35,256–40,352 and leave room for upgrades.
- A club president welcome letter appears after confirming a new Career ground and reflects the chosen Club Outlook. Existing Career saves do not receive a retroactive letter.
- Away match and per-stand stock behaviour from v35.2 are retained.

Saved Career and Sandbox data use their existing `grounds-career-v2` and `stadium-workshop-layered-v35` localStorage keys. Earlier `grounds-career-v1` and `stadium-workshop-layered-v27` records are not removed.
